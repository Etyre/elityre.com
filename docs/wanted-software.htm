Desired software

This is a list of the software tools that I would like to use, and would pay for, if they existed. Some of these, I'll probably sit down and build myself one day.

  • A window-centric session manager for firefox (though I would switch to chrome for this). Described here, here, and here. Smart Sessions is close to what I want, but it's laggy, and still requires too many clicks, and is only available for chrome.
  • A recommendation engine for articles and blog posts that will serve me content, tailored to my interests, without regard for recency. I want to read the best essays of the past 50 years, not the content that other people liked this week or this month.
